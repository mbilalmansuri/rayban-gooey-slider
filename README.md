# Ray-Ban Gooey Slider

A concept Ray-Ban hero section featuring an interactive 3D gooey slider and synchronized text animations.

Scores 95+ across all Lighthouse categories (Performance, Accessibility, Best Practices, and SEO).

[View Live](https://rayban-gooey-slider.vercel.app)

## Features

- Interactive 3D gooey image transitions with Shery.js
- Synchronized text roll animations on click
- Preloader with smooth exit transition

## Built With

- HTML
- Tailwind CSS
- JavaScript
- Shery.js
- GSAP
